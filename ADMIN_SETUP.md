# Beauty Scout / Makeup NK

Лендинг адаптирован под предоставленные настольный и мобильный референсы. Изображения `reference-hero`, `reference-about`, `reference-grid` — иллюстрации для макета, сгенерированные по референсу; это не подтверждённые реальные работы или портрет мастера. Перед публичным запуском замените их реальными фотографиями через админку. `reference-source` — предоставленный пользователем референс, из которого CSS/SVG показывают логотип, ботанические элементы и декоративную карту.

## Что хранится где

- GitHub Pages публикует статическую сборку. Домен makeup-nk.ru остаётся у текущего регистратора.
- `public/content/site.json` содержит тексты, цены, контакты и порядок фотографий.
- `public/media` содержит фотографии. Админка уменьшает новые снимки до 1600 px и не более 900 KB.
- `/admin/` — личный кабинет: услуги и цены, фотографии, тексты и контакты. Есть предпросмотр и подтверждение удаления.
- `worker/index.ts` — API для входа и записи в GitHub. Отдельная база данных не нужна.

Сейчас `public/admin-config.json` не содержит адреса API: публикация из админки недоступна до подключения Worker. Это намеренное начальное состояние, а не готовая работающая авторизация.

## Однократное подключение владельцем

1. Создайте или войдите в аккаунт Cloudflare. Перенос домена и DNS в Cloudflare для адреса workers.dev не требуется.
2. Создайте GitHub fine-grained token только для `Vlad-Lamela/MAKEUP_NK`: Contents — Read and write, Actions — Read. У токена должен быть действующий срок и доступ к ветке main. Токен хранится только в секретах Worker, никогда в репозитории, браузере или переписке.
3. Из корня проекта выполните `npx wrangler@4.147.0 login`, затем `npx wrangler@4.147.0 deploy --config worker/wrangler.jsonc`.
4. Задайте каждый секрет интерактивной командой `npx wrangler@4.147.0 secret put ИМЯ --config worker/wrangler.jsonc`:
   - `GITHUB_TOKEN` — созданный токен;
   - `SESSION_SECRET` — случайная строка длиной минимум 32 символа;
   - `ADMIN_USERNAME` — логин редактора;
   - `ADMIN_PASSWORD` — уникальный пароль длиной минимум 16 символов.
5. Запишите полученный HTTPS адрес Worker в `public/admin-config.json`: `{"apiUrl":"https://makeup-nk-admin.<ваш-поддомен>.workers.dev"}`. Это публичный адрес, не секрет. Сохраните изменение в main.
6. В Settings → Pages должен быть выбран источник GitHub Actions. Workflow `.github/workflows/pages.yml` собирает и публикует `docs`. Ветка main должна разрешать коммиты токена; если есть защита, согласуйте правила для редактора.
7. Откройте `https://makeup-nk.ru/admin/`, войдите и проверьте цикл: изменить тестовую цену, добавить фото, опубликовать, дождаться сообщения о появлении на сайте, проверить страницу, вернуть тестовую цену. Это проверка реального размещения, которую локальные тесты не заменяют.

Cloudflare Free предполагается достаточным для небольшого сайта; фактические лимиты и потребление нужно проверить после развёртывания. Здесь нет платной базы или сервера, но бесплатность сервисов навсегда не гарантируется. Публикация занимает время на сборку GitHub Actions. Личный кабинет отличает сохранение от появления изменений на сайте.

## Поведение редактора

Все новые снимки и текст сохраняются одним Git-коммитом. При конфликте версий чужие изменения не перезаписываются. Сессия и загрузки действуют два часа. После перезагрузки вкладки неопубликованные изменения теряются — браузер предупреждает о выходе. Скрытая карточка скрыта на странице, но не секретна: репозиторий и JSON публичны. Удаление карточки не удаляет старые фотографии из истории Git; периодическая очистка неиспользуемых файлов выполняется владельцем.

Логин не требует GitHub или Cloudflare от мастера. Смена `ADMIN_PASSWORD` отзывает текущие сессии. При истечении GitHub-токена владельцу нужно обновить `GITHUB_TOKEN`.

## Разработка и проверка

```sh
npm ci
npm run typecheck
npm test
npm run build:static
```

В Windows-среде Codex с ограниченным чтением родительских каталогов используется `npm run build:client -- --configLoader runner`, затем `node scripts/prepare-static.mjs`. Для тестов: `node node_modules/vitest/vitest.mjs run --configLoader runner`.

Сборка `docs` создаётся автоматически CI; исходные изменения хранятся в `client`, `shared`, `public`, `worker` и `scripts`. Для локальной демонстрации админки dev-сервер поддерживает `/admin/?demo=1`. В production демонстрационный режим отключён при сборке.

Шрифты Cormorant Garamond и Manrope размещены локально. Лицензии SIL OFL находятся в `public/fonts`. Для проверки дизайна использованы экраны 1440 и 390 px, фильтры галереи, увеличение фото, меню, предпросмотр цены, загрузка/категория/удаление фотографии. Проверки API используют имитацию GitHub; реальная запись и публикация требуют настроенного Worker.
